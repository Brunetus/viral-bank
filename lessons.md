# Viral lessons — the mechanisms layer (TRAINING ONLY)

The WHY layer of the bank: creators explaining HOW virality works, so the
architect internalizes the mechanisms and builds better concepts from the
channel's own material. This is education, not footage.

HARD INVARIANT — TRAINING ONLY, NEVER SPLICED. Nothing catalogued here is a
splice candidate. These reels are someone else teaching a lesson; their frames
never go into a cut. The load-bearing artifact is the WRITTEN lesson below each
entry, not the video. (Content/joke clips that CAN be spliced live in
`catalog.md`; format/trend ideas live in `playbook.md`; this file is neither.)

How the architect uses it: read the lessons to understand the levers of
virality, then apply them to the channel's OWN material. A lesson can confirm,
extend, or contradict a rule in `taste.md` — when it contradicts, `taste.md`
(our own insights-grounded data) wins, and the tension is worth noting.

Entry schema (newest first):
- **source:** creator handle + reel URL
- **mechanism:** the specific lever it teaches (hook retention, the 3-second
  rule, loop/rewatch editing, pattern interrupt, curiosity gap, etc.)
- **the-lesson:** the takeaway transcribed in plain words — what to actually do
- **maps-to:** how it lands against our craft canon (confirms / extends /
  contradicts a `taste.md` rule; names which one)
- **status:** TRAINING-ONLY
- **file:** `clips/<id>.mp4` (gitignored backup; the written lesson above is
  what the architect reads — the video is not required to be present)
