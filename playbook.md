# Viral playbook — the July 2026 meta

Audio-model tag per entry: **diegetic (bakeable)** = the clip/format carries its
own audio, fine to keep in the MP4 · **trending sound (add in-app)** = a licensed
IG-library track; never bake it in, select it natively when posting from the phone
(business accounts get muted/throttled for uploaded copyrighted audio) · **flexible**
= works either way.

Banked footage exists for a concept only where noted `→ clips/`.

**96.
